# 앜~!!엌~!! 복불복게임 기획서

## 1. 기본 항목 5개
- **대상 사용자** : 복불복 게임을 하려는 2명이상 10명이하의 소규모 그룹
- **사용 목적** : 모임이나 소규모 그룹 내에서 빠르고 긴장감 있게 벌칙자나 순서를 정하기 위한 복불복 게임
- **화면 구성과 동작** : 
  - 상단에 게임 타이틀('앜~!!엌~!! 복불복게임')과 상태 메시지가 표시됩니다.
  - 게임 시작 시 '게임 시작하기' 팝업(모달)이 노출됩니다.
  - 화면 중앙에 악어 얼굴 일러스트(SVG/CSS)가 배치되며, 아랫턱에 13개의 이빨 버튼이 나열됩니다.
  - 카드를 클릭하듯 이빨을 클릭하면 별도의 소리나 팝업 없이 해당 이빨만 아래로 쏙 내려갑니다.
  - 랜덤으로 지정된 1개의 당첨 이빨을 누르면 악어 윗턱이 내려오는 '입 닫힘 애니메이션'이 실행됩니다.
  - 게임 종료 후 결과 안내와 '다시 하기' 버튼이 포함된 팝업이 화면 중앙에 나타납니다.
- **필요한 자료** : 
  - 악어 UI 구성용 SVG/CSS 코드
  - 스타트 및 결과 모달 팝업 HTML/CSS 구조
- **완료 기준** : 
  - 13개의 이빨 중 무작위로 1개의 당첨 이빨이 매 회차 생성됩니다.
  - 안전한 이빨을 누르면 시각적 효과(이빨 쏙 들어감)만 적용되고 팝업이나 멘트가 뜨지 않습니다.
  - 당첨 이빨을 누르면 악어 입이 닫히는 애니메이션과 함께 당첨 팝업창이 정상 노출됩니다.
  - '다시 하기' 버튼 클릭 시 게임이 초기화되어 새 당첨 위치가 지정됩니다.
  - 단일 HTML 파일로 동작하여 외부 서버나 회원가입 없이 브라우저에서 바로 열립니다.

## 2. 필수 기능과 추가 기능
- **필수 기능** : 
  - 13개 고정 이빨 배치 및 회차별 1개 무작위 당첨 로직
  - 안전 이빨 클릭 시 이빨 숨김 처리 (소리/멘트 없음)
  - 당첨 이빨 클릭 시 악어 입 닫힘 애니메이션 연출
  - 스타트 팝업 및 결과/재시작(다시 하기) 팝업 제공
- **추가 기능** : 
  - 게임 상단 '앜~!!엌~!! 복불복게임' 타이틀 표시
  - 반응형 디자인 (모바일 및 PC 브라우저 자동 맞춤)
  - 이빨 클릭 중복 방지 (이미 누른 이빨 비활성화)

## 3. 한계 및 비목표 3가지
- **한 계** : 
  - 순수 프론트엔드 단일 HTML 파일로 구성되어 브라우저를 새로고침하면 이전 게임 상태나 누적 통계는 유지되지 않습니다.
- **비목표** : 
  1. 음향 효과(사운드/효과음) 및 음성 출력 기능 구현 제외
  2. 사용자 이름 입력, 순서 지정, 턴(Turn) 자동 계산 시스템 제외
  3. 회원가입, 로그인, 데이터베이스 연동 및 외부 서버 구축 제외

## 4. 검증 방법 1가지
- **검증 방법** : 
  - 웹 브라우저(Chrome, Safari 등)에서 HTML 파일을 직접 열어 13개 이빨을 차례로 클릭하며, 안전 이빨 클릭 시 무반응(이빨 내려감만 발생) 및 당첨 이빨 클릭 시 입 닫힘 애니메이션과 결과 팝업창이 제대로 뜨는지 연속 5회 리셋 테스트를 진행하여 검증합니다.
