# 🎬 영화 티어리스트 웹 애플리케이션 기획서

## 1. 누가 쓰나 (사용 대상)
* 개인적으로 본 영화를 정리하고, 완성된 티어리스트를 다른 사람들과 공유하고자 하는 사용자

## 2. 무엇을 하려고 (목적)
* 자신이 지금까지 본 영화들을 등급(티어)별로 한눈에 모아보고 정리하기 위함

## 3. 화면과 동작
* **티어 구성**: 
  * 기본 6개 티어 제공 (`S`, `A`, `B`, `C`, `D`, `E`)
  * 사용자가 원하는 대로 티어를 직접 추가하거나 삭제하는 기능 제공
* **영화 카드 추가 방식**: 
  * 영화 제목과 포스터 이미지(파일 선택 또는 URL 입력)를 직접 입력하여 영화 카드를 생성하는 방식
* **배치 방식**: 
  * 마우스 드래그 앤 드롭(Drag & Drop)으로 영화 카드를 원하는 티어 칸으로 자유롭게 이동
* **데이터 저장 방식**: 
  * 브라우저 로컬 스토리지(LocalStorage)를 활용하여 페이지를 새로고침하거나 브라우저를 닫았다가 다시 접속해도 기존 티어 및 영화 배치가 그대로 유지됨

## 4. 필요한 자료
* 외부 서버나 별도 데이터베이스(DB) 없이 **단일 HTML 파일(HTML, CSS, JavaScript 포함)**로 동작하는 형태
* 영화 포스터 이미지 (사용자 직접 업로드 또는 이미지 URL 링크)

## 5. 완성 기준 (직접 테스트 가능한 기준)
* [ ] 영화 제목과 포스터 이미지를 입력하여 새로운 영화 카드를 생성할 수 있다.
* [ ] 생성된 영화 카드를 마우스 드래그 앤 드롭하여 `S, A, B, C, D, E` 등 원하는 티어 칸으로 옮길 수 있다.
* [ ] 새로운 티어 항목을 추가하거나 기존 티어 항목을 삭제할 수 있다.
* [ ] 영화를 S칸에 옮긴 후 브라우저를 새로고침하거나 닫았다가 다시 열어도 영화가 S칸에 그대로 유지되어 남아있다.
